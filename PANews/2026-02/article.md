# February 2026 Article
It's been a while so let's catch up on everything that has happened with Project Arrhythmia since October 2025!
- Original Battle Cube Game Found
- Project Arrhythmia 1.0.0 Demo Found
- Story Mode Playtest 2
- BetterLegacy Split Snapshot Cycle

## Original Battle Cube Game Found
The creator of the original Battle Cube game that first inspired Project Arrhythmia was contacted about a build of the game, and they still have it.  
There isn't a proper way to get the game yet so we'll keep you updated on any developments related to it.  

## Project Arrhythmia 1.0.0 Demo Found
Ever since 2018, the 1.0.0 version of Project Arrhythmia was sitting around in a Google Drive link in the VG server completely unknown to us.  
Until the link was discovered. Unfortunately the link has since been privated / removed so the 1.0.0 version is no longer available, but some people have the build so at least it's out there.  
With it we also discovered the artist of the song present in this first demo: Foxberry (once known as Radiogiraffe). You can find them as @foxburial.bsky.social on Bluesky, they're currently working on a cute looking metroidvania game!  
The themes from this version and the modern version have been ported to BetterLegacy.  

## Story Mode Playtest 2
The second story mode playtest is about to begin, with bosses as the focus this time. More information can be found on the Steam post.  

## BetterLegacy Split Snapshot Cycle
The 1.9.0 update for BetterLegacy is currently undetermined. It will either be a story update or an online multiplayer update.  
To solve this, the snapshot cycle for the future update has been split into two groups.  

### Story Playtest
Will be based on the main branch every time it updates.  
### Multiplayer Testing
Some changes / features might not match the main branch as multiplayer development will be done separately from the main branch.  

If there is enough story content to warrant a full release, then 1.9.0 will be the story update. Otherwise, 1.9.0 will be the multiplayer update if that is done before the story is.
